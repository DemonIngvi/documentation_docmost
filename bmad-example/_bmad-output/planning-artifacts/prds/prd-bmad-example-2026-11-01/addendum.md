# Дополнение к PRD: Вектор

> Учебный пример. Здесь хранятся материалы, которые важны следующим шагам, но не относятся к самому PRD.

## Отвергнутые варианты

| Вариант | Почему отвергнут |
| --- | --- |
| Чат-ассистент как главный интерфейс | Результат отделён от работы, его трудно проверить |
| ИИ применяет изменения сам, с возможностью отмены | Главная причина провала в pre-mortem: потеря доверия к доске |
| Простая модель из задач и досок | Целевые команды работают с несколькими Project и Team |
| Только облачная поставка | Не подходит компаниям с закрытым контуром |

## Заметки для архитектуры

- AI Suggestion лучше хранить отдельно от Work Item: тогда правило «без подтверждения данные не меняются» проверяется схемой.
- Поиск дублей требует векторного представления Request и Work Item.
- Board обновляется в реальном времени.
