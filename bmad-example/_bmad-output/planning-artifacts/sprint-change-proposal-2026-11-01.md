# Sprint Change Proposal: локальная модель

> Учебный пример: вымышленный продукт. Заказчик и событие смоделированы, чтобы показать `bmad-correct-course`. Изменения уже внесены в PRD и эпики.

## 1. Сводка проблемы

Во время Эпика 1 пилотный заказчик сообщил, что требования безопасности запрещают отправлять текст Work Item внешнему провайдеру. PRD предполагал только внешнюю модель, значит пилот без изменений невозможен.

## 2. Анализ влияния

| Артефакт | Влияние |
| --- | --- |
| PRD | Расширить FR-16, добавить NFR-3 |
| Архитектура | Добавить AD-5, скрыть модель за портом |
| UX | Добавить состояния «модель недоступна» и «ИИ отключён» |
| Эпики | Расширить критерии истории 5.1 |
| Эпик 1 | Не затронут |

## 3. Рекомендованный путь

Прямая корректировка без отката: Эпик 5 ещё не начат. Перезапуск планирования не нужен.

## 4. Подробные изменения

**PRD, FR-16.** Было: «Administrator может подключить внешнего провайдера». Стало: «Administrator может создать Model Connection к внешнему провайдеру или локальной модели и отключить ИИ для Project».

**Архитектура.** Добавлено правило AD-5: к модели обращается только порт `ModelProvider`.

**История 5.1.** Добавлены критерии о локальной модели и отключении ИИ.

## 5. Передача

Объём изменений небольшой. Руководитель продукта подтверждает, разработчики продолжают спринт.

**Решение:** одобрено в рамках примера.
