# Вектор — Experience Spine

> Учебный пример: вымышленный продукт. Режим Fast path: решения предложены ИИ.

## Foundation

Адаптивный веб для рабочего компьютера, основная ширина от 1280 px. `DESIGN.md` задаёт внешний вид, этот документ задаёт поведение. Термины как в Глоссарии PRD.

## Information Architecture

| Экран | Откуда | Назначение |
| --- | --- | --- |
| Мои задачи | Вход в систему | Назначенные мне Work Item |
| Views | Левая панель | Board, List и Roadmap |
| Планирование | Левая панель | Release, Iteration, Team Iteration |
| Входящие | Левая панель | Новые Request |
| Dashboards | Левая панель | Срезы для руководителей |
| Настройки | Меню профиля | Process, Team, Role, Model Connection |

Карточка Work Item открывается боковой панелью поверх любого экрана.

→ Макеты: `mockups/board.html`, `mockups/ai-decomposition.html`. При расхождении главнее этот документ.

## Voice and Tone

| Так | Не так |
| --- | --- |
| «Предложение ИИ. Проверьте перед применением.» | «ИИ всё сделал за вас!» |
| «Переход запрещён: сначала нужен State „Ревью“.» | «Ошибка 422» |
| «Модель недоступна. Создайте User Story вручную.» | «Что-то пошло не так» |
| «Такой фильтр построить нельзя: нет поля „настроение“.» | Приблизительный результат без объяснения |

## Component Patterns

| Компонент | Где | Поведение |
| --- | --- | --- |
| Карточка | Board, Roadmap | Клик открывает панель. Перетаскивание меняет State или даты. |
| Колонка | Board | Счётчик и WIP-лимит. Превышение подсвечивается, перенос разрешён. |
| Блок предложения ИИ | Feature, Request, List | Действия применяются к одному черновику или ко всем. |
| Конструктор фильтра | List | Условия редактируются вручную, AI-фильтр заполняет те же поля. |

## State Patterns

| Состояние | Поведение |
| --- | --- |
| Пусто | Объяснение и одно действие: «Создать Feature» |
| Загрузка ИИ | Индикатор в блоке, интерфейс остаётся рабочим, есть «Отменить» |
| Модель недоступна | Причина в блоке, ручные действия работают |
| ИИ отключён | AI-элементы не показываются |
| Конфликт изменений | Карточка обновляется, пользователь видит, кто изменил |

## Interaction Primitives

- `C` создать Work Item, `/` поиск, `Esc` закрыть панель.
- На Board стрелки выбирают карточку, `Space` берёт её, стрелки переносят, `Space` кладёт.
- Отмена применения AI Suggestion доступна в уведомлении в течение 30 секунд.

## Accessibility Floor

WCAG 2.1 AA. Всё доступно с клавиатуры, включая перенос карточек. Смена статуса объявляется экранному диктору. Подсветка всегда дублируется значком или текстом.

## Key Flows

### Лина применяет декомпозицию (UJ-1)

1. Лина открывает Feature и нажимает «Предложить декомпозицию».
2. В блоке появляется индикатор, она продолжает читать описание.
3. Появляются черновики User Story с критериями приёмки.
4. Лина удаляет один и правит другой.
5. **Кульминация:** она нажимает «Применить», User Story появляются в Feature.
6. Уведомление предлагает отмену, запись уходит в AI Journal.

### Дима двигает карточку (UJ-4)

1. Дима открывает Board своей Team Iteration.
2. Перетаскивает карточку через одну колонку.
3. **Кульминация:** карточка возвращается, подсказка объясняет разрешённый переход.
4. Дима переносит её в соседнюю колонку.
